POST /orders

Creates a new enterprise order transaction.

Request Body (JSON):
{
  "customerId": "string",
  "shippingRegion": "DOMESTIC|EU|INTERNATIONAL",
  "items": [
    {
      "productId": "string",
      "productName": "string",
      "quantity": number,
      "unitPrice": number
    }
  ]
}

Response: 200 OK — Order JSON
GET /orders/{id}

Retrieves order entity by UUID.

Path Parameter:
id — UUID string

Response:
200 OK — Order JSON
404 Not Found — order does not exist
GET /orders/{id}/total

Calculates total price with discounts and shipping costs.

Path Parameter:
id — UUID string

Query Parameters:
express (boolean, default: false) — express shipping surcharge
coupon (string, optional) — discount coupon code

Quantity Discount Rules (per line item):
• 3–4 units: 5% off that line
• 5+ units: 10% off that line

Demo Coupon Codes:
SOMMER10 — 10% off (stackable)
RABATT5 — €5 off, min. €20 (stackable)
VIP20 — 20% off, min. €50 (exclusive)

Coupon Types:
PERCENTAGE: % of subtotal after qty discounts
FIXED_AMOUNT: flat deduction, min(value, subtotal)
exclusive=true: only best of qty/coupon applies

Response:
200 OK — { "total": 42.00 }
404 Not Found
